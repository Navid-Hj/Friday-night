# PooPoo's Date Website

1. Put your photos into the `assets` folder using these names:
   - photo1.jpg = opening photo of you two
   - poopoo_wrong.jpg = funny/disappointed photo of PooPoo
   - photo2.jpg through photo12.jpg = book photos
2. Open `index.html` in a browser to test it.
3. For hosting, upload the whole folder to GitHub Pages, Netlify, or Vercel.

The website is intentionally written so the wording and photos are easy to change.
